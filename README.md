# Census Income Classification - PyTorch

Built with PyTorch, 30,000 entries, 3 hidden layers (128-64-32), seed 42.

**Results:**
- Accuracy: 84.70%
- Precision: 74.22%
- Recall: 56.46%
- F1: 64.14%
- Confusion Matrix: [[1972, 132], [293, 380]]

**Files:**
- census_income_workshop.ipynb - Training notebook
- income.csv - Dataset
- model.pth - Trained model (52KB)
